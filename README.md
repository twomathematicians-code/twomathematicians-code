### 🔄 Typical ML Pipeline — From Research to Production

```mermaid
sequenceDiagram
    actor DS as Data Scientist
    participant NB as Notebook
    participant EXP as Experiment
    participant MLF as MLflow
    participant CD as CI/CD
    participant API as FastAPI
    participant PROD as Production

    DS->>NB: Exploratory Analysis
    NB->>EXP: Feature Engineering
    EXP->>MLF: Track Experiment
    MLF->>MLF: Log Metrics & Params
    MLF->>CD: Register Model
    CD->>CD: Run Test Suite (380+)
    CD->>API: Deploy with DVC
    API->>PROD: Serve Predictions
    PROD->>MLF: Feedback Loop
    Note over DS,PROD: End-to-End MLOps Pipeline
```
